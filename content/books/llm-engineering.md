## What You'll Learn

LLMs are powerful, but getting them to behave reliably in production is a engineering discipline, not a party trick. This book covers the patterns that separate demos from shipped products.

**Topics covered:**

- Prompt engineering patterns: chain-of-thought, few-shot, structured output
- Building Retrieval-Augmented Generation (RAG) pipelines
- Choosing between embedding models and when to fine-tune
- Evaluating LLM outputs systematically (not just eyeballing them)
- Managing latency and cost with caching and model routing
- Handling failure modes: hallucinations, context window limits, rate limiting

## Who This Is For

Software engineers who have played with the OpenAI API and now need to build systems that are testable, observable, and cost-effective.
