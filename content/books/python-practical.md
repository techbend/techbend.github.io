## What You'll Learn

This book bridges the gap between tutorial-level Python and shipping real applications. It assumes you know the basics and focuses on the pragmatic decisions that make code maintainable at scale.

**Topics covered:**

- Structuring large Python projects with clear module boundaries
- Building web APIs with FastAPI and Django REST Framework
- Writing tests that actually catch bugs (pytest, fixtures, mocks)
- Dockerizing applications for consistent deployments
- Managing configuration across development, staging, and production
- Handling errors and logging in a way that helps you debug at 3 AM

## Who This Is For

Intermediate Python developers who have built a few scripts or small apps and want to level up to building systems that other developers can work on without confusion.
